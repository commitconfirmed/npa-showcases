## Examples

Showcases of Networking and Automation concepts here. Each example has its own readme and (eventually) blog post. Brief descriptions below

### basic-golang

[basic-golang](./basic-golang/): A basic lab with a server with golang installed to test go programs against network devices

### basic-netbox

[basic-netbox](./basic-netbox/): A lab going over the basics of netbox and some basic ways you can interact with it to import data and how you can hook Ansible & Nornir into it.

### basic-nornir

[basic-nornir](./basic-nornir/): A lab with a Nornir server and some basic examples for interacting with Arista & Juniper Network OS's. 

### intermediate-ceos-ixp

[intermediate-ceos-ixp](./intermediate-ceos-ixp/): A lab demonstrating an Internet eXchange Point

### intermediate-junos-sr

[intermediate-junos-sr](./intermediate-junos-sr/): A Intermediate JunOS Segment Routing lab example. License required for full functionality
